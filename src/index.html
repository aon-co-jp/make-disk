    4.1. Dolby/サラウンド対応の範囲 / Dolby & surround support

    Dolby Vision / Dolby Atmos / Dolby Cinema / IMAX Enhanced / 4DX は各社のライセンス制フォーマットで、make-diskがこれらを新規に生成(エンコード)することはできません。代わりに、(1)元素材に含まれるDolby Vision・Atmos・5.1/7.1サラウンドを壊さない「無変換コピー」、(2)互換性のある下位形式(HDR10、Dolby Digital / Digital Plus、AAC/Opusのサラウンド)への変換、(3)元素材の検出結果のログ表示、に対応します。
    These are licensed formats; make-disk cannot newly encode Dolby Vision / Atmos / IMAX / 4DX. It can (1) losslessly copy existing Dolby Vision / Atmos / surround tracks, (2) convert to compatible lower formats (HDR10, Dolby Digital / Plus, surround AAC/Opus), and (3) report what it detects in the source. HDR10 conversion keeps the base layer; Dolby Vision dynamic metadata is dropped.

    4.2. 解像度・フレームレート(動画) / Resolution & frame rate (video)

    DVDは通常解像度(720×480)とフルHD、ブルーレイはフルHDと4Kが選べます。 カスタムで720×480〜5K/8Kまで自由に指定することもできます。
    DVD supports standard (720x480) or Full HD; Blu-ray supports Full HD or 4K. Custom lets you specify anything from 720x480 up to 5K/8K.

    Note: "AI-optimized" detects the source frame rate and snaps it to the nearest of 24/30/60/120 — it does not perform semantic motion analysis.

    4.5. PDF見開き変換(最大4K、右綴じ/左綴じ) / PDF spread conversion (up to 4K, right/left binding)

    ソースファイルに含まれるPDF(1で追加)を、見開き2ページを1枚に合成した画像として書き出します。
    Converts PDFs (added in section 1) into images with two facing pages composited into one spread.


    ※PDFのラスタライズにはpoppler-utils(pdftoppm/pdfinfo)が必要です(現時点では未同梱、実行環境に別途インストールされている場合のみ動作します)。
    Note: rendering PDFs currently requires poppler-utils (pdftoppm/pdfinfo) to already be installed on the system — it is not yet bundled.

    元のPDFはそのまま保持し、出力先フォルダへ「元のファイル名-rebind.pdf」として別名保存します。PDF自体(画像化せず)を編集するため、スキャナ出力等の単純な構造のPDFのみ対応します。
    The original PDF is left untouched; the result is saved as "<original filename>-rebind.pdf" in the output folder. This edits the PDF itself (no rasterization), so it only supports simple, flat page-tree PDFs such as scanner output.
