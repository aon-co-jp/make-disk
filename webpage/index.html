make-disk

CD / DVD / Blu-ray 書き込み ＆ フォーマット変換 GUIアプリ
Cross-platform disc writing & format conversion GUI app

WindowsmacOSLinux オープンソース / Open Source (MIT)

make-diskは、Windows・macOS・Linuxで同じ操作性を持つ、CD/DVD/Blu-ray 書き込みと音声・動画フォーマット変換のためのデスクトップアプリです。 ブラウザ上では動作しません。お使いのPCにインストーラーを ダウンロードし、インストールしてご利用いただくネイティブアプリです。

make-disk is a native desktop app for CD/DVD/Blu-ray writing and audio/video format conversion, with the same UI across Windows, macOS, and Linux. It does not run in the browser — download the installer for your OS and run it locally.

主な機能 / Features

  • 出力先フォルダの指定 / Choose an output folder
  • CD・DVD・Blu-ray(DL含む)への書き込みを複数種別同時選択 / Write to CD, DVD, or Blu-ray — multiple disc types at once
  • 書き込み速度: 自動判定・最高速・速度指定 / Write speed: auto, maximum, or fixed
  • 有名な音声フォーマット(MP3・WAV・FLAC・AAC・OGG)を複数選択して変換 / Convert to well-known audio formats (MP3, WAV, FLAC, AAC, OGG) — multi-select
  • 有名な動画フォーマット(MP4・MKV・AVI・MOV・WebM)を複数選択して変換 / Convert to well-known video formats (MP4, MKV, AVI, MOV, WebM) — multi-select
  • 音声・動画いずれもISOイメージへ出力可能 / Export either audio or video output to an ISO image
  • ファイルごとの時間指定・トリミング(5分・10分等)/ Per-file time trimming (5 min, 10 min, etc.)
  • ビットレート: 固定 or ディスク容量から自動算出した最大値 / Bitrate: fixed, or auto-maximized to disc capacity

必要な外部ツール / Requirements

コーデックや書き込み処理は既存のオープンソースエンジンをラップしています。 実行にはFFmpegと GNU xorrisoを あらかじめインストールしておいてください。
This app wraps existing open-source engines rather than reimplementing codecs or burning logic. Please pre-install FFmpeg and GNU xorriso before running it.

Windows向けには、それぞれをインストーラー付きで簡単に導入できる Rustリスペクト版もご用意しています。ただし現時点では make-disk本体からの完全な代替にはなりません (実機検証済み: rs-xorrisoはISO生成のみ対応・長いファイル名は 切り詰め・ディスク書き込み機能は無し、rs-ffmpegは無圧縮WAVの probe/変換のみ対応・コーデック指定やビットレート制御は非対応)。
For Windows, we also offer Rust tribute versions of each with a one-command installer. Note: as of now these are not full substitutes for what make-disk itself needs (verified: rs-xorriso only creates ISO images — long filenames get truncated and there is no disc-burning — and rs-ffmpeg only probes/converts uncompressed WAV, with no codec selection or bitrate control).

  • FFmpeg — フォーマット変換・ビットレート制御 / format conversion & bitrate control ・ Windows版はRustでリスペクト: rs-FFmpeg (Rust tribute for Windows: rs-FFmpeg)
  • xorriso — ISO生成・ディスク書き込み / ISO creation & disc burning ・ Windows版はRustでリスペクト: rs-xorriso (Rust tribute for Windows: rs-xorriso)
